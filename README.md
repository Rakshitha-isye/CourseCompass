# 🎓 CourseCompass
### Personalized E-Learning Recommendation System

**CourseCompass** is a personalized e-learning recommendation platform that helps learners discover suitable online courses based on their interests, preferences, and learning activities.

The main goal is to make online learning easier by helping users find relevant courses and useful learning resources.

## 🚀 Key Features

- **User Registration and Login** – Secure user account creation and login.
- **Course Exploration** – Browse and search available courses.
- **Personalized Recommendations** – Discover courses based on user interests and learning activities.
- **Course Ratings and Feedback** – Rate courses and share feedback.
- **User Interaction Tracking** – Track user activities to support personalized recommendations.
- **Course Details** – View individual course information.
- **Learning Resources** – Access useful tutorials and external learning materials.

## ⚙️ How It Works

1. Users create an account and log in.
2. They explore available courses.
3. Their interests, preferences, and learning activities help personalize course recommendations.
4. Users can view course details and ratings.
5. They can access relevant learning resources to improve their skills.

## 💻 Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Rakshitha-isye/CourseCompass.git
```

### 2. Navigate to the Project Folder

```bash
cd CourseCompass
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

### 4. Activate the Virtual Environment

**Windows PowerShell:**

```powershell
.\venv\Scripts\Activate.ps1
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the Application

```bash
python app.py
```

Open the local URL displayed in your terminal in a web browser.
