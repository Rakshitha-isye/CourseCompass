# CourseCompass
### Personalized E-Learning Recommendation System

**CourseCompass** is a personalized e-learning recommendation platform designed to help learners discover suitable courses based on their interests, preferences, and learning activities.

## Key Features
- User Registration and Login
- Course Exploration and Search
- Personalized Course Recommendations
- Course Ratings and Feedback
- User Interaction Tracking
- Individual Course Details
- Learning Resources

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS
- Machine Learning

## Project Objective
To improve the online learning experience by recommending relevant courses and helping learners find useful educational resources.
